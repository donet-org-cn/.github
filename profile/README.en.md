## Open code. Shared future.

**.NET China** is an independent developer-led open-source community focused on C#, .NET, AI, foundational engines, and cross-platform applications. We connect real projects, reproducible experiments, and developers who enjoy sharing what they learn.

GitHub organization: **donet-org-cn** · Website: **[dotnet.org.cn](https://dotnet.org.cn/en/)**. We are not affiliated with Microsoft and do not represent an official Microsoft organization.

## Participate

- Share ideas and real-world experiments in [Discussions](https://github.com/donet-org-cn/community/discussions).
- Report a project-specific problem in that repository's Issues, with versions, environment, and reproduction steps.
- Improve documentation, code, or tests through a focused pull request, following the project's contribution guidelines.
- Explore the website's [project introductions](https://dotnet.org.cn/en/#projects) and [About page](https://dotnet.org.cn/en/about/).

You do not need organization membership to participate. Project adoption, repository transfers, and membership will develop around actual maintenance needs.
