## 用开放的代码，创造无限可能

**.NET 中国**是由开发者发起的独立开源社区，聚焦 C#、.NET、人工智能、基础引擎与跨平台应用。我们希望把真实项目、可复现的实践和愿意分享的开发者连接起来。

GitHub 组织：**donet-org-cn** · 官网：**[dotnet.org.cn](https://dotnet.org.cn)**。我们是独立开发者社区，非微软官方网站或官方机构。

## 一起参与

- **交流想法、展示实践**：前往 [Community Discussions](https://github.com/donet-org-cn/community/discussions)。
- **报告具体项目问题**：在对应项目仓库提交 Issue，附上版本、运行环境和可复现步骤。
- **完善文档、代码或测试**：阅读项目自己的贡献说明，提交聚焦的小型 Pull Request。
- **了解项目背景**：官网提供[独立项目介绍页](https://dotnet.org.cn/#projects)与[关于我们](https://dotnet.org.cn/about/)，支持中英双语。

参与交流无需先成为组织成员。项目接纳、仓库迁移和成员协作将结合实际维护需求逐步开展。
